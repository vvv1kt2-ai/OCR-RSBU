# 02 — Профиль поставщика и чистая сборка запроса

**What to build:** поставщик ИИ перестаёт быть свойством кода и становится профилем.
Один документ прогоняется на Polza через новый путь и даёт **тот же результат**, не
создавая ни одного нового файла кэша — то есть не сделав ни одного нового вызова и не
потратив ни рубля. Это префактор: поведение не меняется, меняется устройство.

**Blocked by:** 01 (правка кода начинается только после положительного вердикта)

**Status:** done

- [x] Профиль описывает поставщика целиком: адрес точки чата, имя ключа в файле
      учётных данных, соответствие трёх ролей моделей конкретным адресам, таблица цен,
      короткая метка для ключей кэша
- [x] Реестр профилей содержит Polza; активный профиль выбирается переменной
      окружения, значение по умолчанию — Polza
- [x] Сборка запроса — **чистая функция**: по профилю, адресу модели и сообщениям
      возвращает адрес, заголовки и тело запроса, ничего не отправляя
- [x] Сетевой ввод-вывод остаётся ровно в одном месте
- [x] **Имена трёх ролей моделей сохраняются** — меняется только источник их значений.
      Внешние скрипты и существующие тесты не правятся
- [x] Неизвестная модель даёт **громкое предупреждение**, а не молчаливый нуль: сейчас
      отсутствие модели в таблице цен незаметно искажает отчёт о стоимости
- [x] Отсутствие ключа в файле учётных данных даёт понятную ошибку с именем ключа
- [x] Прогон одного документа на Polza даёт прежний результат и **не создаёт новых
      файлов кэша** (проверяется сравнением списка файлов до и после)
- [x] Пользователь заполняет адреса моделей в JSON-файле профилей; в исходном коде
      адресов нет
- [x] Все три существующих набора тестов зелёные; добавлен новый набор на сборку
      запроса и подсчёт цены
- [x] Контрольные суммы свода не изменились

**Note for the implementer:** названия моделей в этой среде при выводе команд и чтении
файлов подменяются пустой строкой. Python читает настоящие значения, слепнет только
вывод. Всё, что касается идентификаторов моделей, сверять численно — длина и `sha1`,
и не вписывать их в код.
