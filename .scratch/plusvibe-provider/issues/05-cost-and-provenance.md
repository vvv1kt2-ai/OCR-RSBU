# 05 — Цена из ответа поставщика и происхождение в результате

**What to build:** отчёт о стоимости перестаёт зависеть от устаревшего прайс-листа, а
в результате документа видно, каким поставщиком сделана транскрипция. Через месяц
можно понять происхождение каждой цифры и сколько она стоила.

**Blocked by:** 04

**Status:** done

- [x] Цена вызова берётся из заголовка ответа, когда поставщик её сообщает; иначе —
      расчётом по таблице профиля
- [x] В манифесте видно фактическую стоимость прогона и число сделанных вызовов
- [x] В результате документа записан поставщик рядом с уже существующим полем модели
- [x] При отсутствии цены в ответе и в таблице — **предупреждение**, а не тихий нуль
- [x] Итог отчёта сходится с ручной проверкой по заголовкам ответов
- [x] Добавлены тесты подсчёта цены: заголовок есть / заголовка нет / модель неизвестна
- [x] Все три существующих набора тестов зелёные
- [x] Контрольные суммы свода не изменились

**Note for the implementer:** поставщик может не отдавать заголовок со стоимостью —
тогда путь через таблицу профиля остаётся основным, и он тоже должен быть покрыт
тестом. Молчаливый нуль при неизвестной модели — это дефект, а не удобное поведение:
именно он способен незаметно исказить отчёт о стоимости.
