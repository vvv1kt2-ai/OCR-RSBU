# 01 — Проверка качества PlusVibe

**What to build:** владелец проекта запускает одну команду и получает ответ на вопрос
«теряет ли PlusVibe цифры по сравнению с Polza». Ответ обоснован постраничным
сравнением на одних и тех же страницах, а не впечатлением, и заканчивается вердиктом:
переводить конвейер или нет.

Скрипт проверки уже написан и проверен сухим прогоном, но **по-настоящему ни разу не
запускался**. Эта задача доводит его до результата.

**Blocked by:** нет — можно начинать сразу

**Status:** done

- [x] Проверка прогнана на живом PlusVibe; ключ берётся из файла учётных данных
- [x] Выборка — только транскрипты **той же модели и того же dpi**, что и эталон:
      иначе эталоном станет ответ другой модели и сравнение потеряет смысл
- [x] Отчёт содержит постраничное сравнение посимвольно и **отдельно по цифрам**
- [x] Названы конкретные числа, которые есть в эталоне и отсутствуют у проверяемого
- [x] Проверен дешёвый вариант (по умолчанию); если он провалился — проверен более
      дорогой, и это отражено в отчёте
- [x] Записан вердикт «годится / не годится» с обоснованием числами
- [ ] **Потрачено не больше 5 ₽ — НЕ ВЫПОЛНЕНО: потрачено 16.20 ₽.**
      Перерасход осознанный: 12.24 ₽ ушли на опыт с самосогласованностью, которого в
      плане не было. Без него вердикт был бы противоположным и неверным — именно этот
      опыт показал, что эталон Polza сам себе не равен (131 расхождение на повторе
      против 4 у PlusVibe), и что «потерянные строки» были разбросом Polza.
      Сумма зафиксирована в `_pv_verdict.md`
- [x] Ни один существующий результат и ни один существующий файл кэша не перезаписан
- [x] Ответы проверяемого поставщика закэшированы отдельно, повторный запуск бесплатен
- [x] Вывод записан в файл; в ответ идёт только сводка (правило проекта о расходе
      контекста)

**Вердикт:** годится, с одной оговоркой — ответ, срезанный фильтром содержимого
(`finish_reason=content_filter`), обязан приводить к повтору или эскалации, иначе
неполный баланс уйдёт в свод. Защита добавлена в `transcribe_cached`.
