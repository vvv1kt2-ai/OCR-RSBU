# Метки триажа

Скиллы говорят о пяти канонических ролях. Этот файл отображает роли на реальные
строки меток в трекере проекта.

| Метка в mattpocock/skills | Метка в нашем трекере | Смысл                                |
| ------------------------- | --------------------- | ------------------------------------ |
| `needs-triage`            | `needs-triage`        | Нужно оценить задачу                 |
| `needs-info`              | `needs-info`          | Ждём информацию от автора            |
| `ready-for-agent`         | `ready-for-agent`     | Полностью описана, готова для агента |
| `ready-for-human`         | `ready-for-human`     | Требует работы человека              |
| `wontfix`                 | `wontfix`             | Решено не делать                     |

Когда скилл называет роль (напр. «поставь метку готовности для агента»), брать строку
из правой колонки.

Правую колонку можно менять — под свой словарь. Менять левую нельзя: по ней скиллы
находят роль.
